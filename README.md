# Nihat Cengiz Pamuk — Portfolio & Interactive CV

> Elektrik-Elektronik Mühendisi & Biyomedikal Mühendisi

Bu repo, Nihat Cengiz Pamuk'un kişisel portfolyosunu ve interaktif web özgeçmişini içerir. GitHub Pages üzerinden doğrudan web tarayıcısında görüntülenebilir ve paylaşılabilir.

## 🚀 Canlı Web Adresi (GitHub Pages)

Web CV'nize şu bağlantıdan ulaşabilirsiniz:
👉 **[https://nihatcengiz.github.io/cv/](https://nihatcengiz.github.io/cv/)**

---

## ⚡ Öne Çıkan Özellikler

- **Çift Dil Desteği (TR / EN):** Tek tıkla Türkçe ve İngilizce dilleri arasında dinamik geçiş.
- **Koyu / Açık Tema:** Gece ve gündüz kullanımına uygun, modern ve göz yormayan arayüz tasarımı.
- **3D Donanım Galerisi (Modal Lightbox):**
  - **UPS Ana Kontrol Kartı** — STM32 Tabanlı Merkezi Anakart
  - **Flyback SMPS** Güç Katı Devre Kartı
  - **İzole IGBT Sürücü Kartı** (Gate Driver)
  - **Tristör (SCR)** Darbe Trafolu Tetikleme Kartı
- **Doğrudan PDF İndirme:** Hem Türkçe hem de İngilizce orijinal PDF CV'leri tek tıkla indirebilme.
- **Yazdırılabilir CV Şablonu:** `Ctrl + P` veya sayfadaki "Yazdır" butonuyla temiz, renk tasarruflu fiziksel/PDF çıktısı.
- **Hızlı İletişim:** E-posta kopyalama, LinkedIn ve GitHub profil bağlantıları.

## 🛠️ GitHub Pages Kurulumu (Nasıl Yayına Alınır?)

1. GitHub hesabınızda oturum açın ve **New repository** (Yeni repo) oluşturun (Örn: `cv` veya `<kullanici-adiniz>.github.io`).
2. Bu klasördeki dosyaları repoya yükleyin (Git komutları ile veya GitHub web arayüzünden sürükleyip bırakarak).
3. GitHub reponuzda **Settings (Ayarlar) > Pages** sekmesine gidin.
4. **Branch** kısmında `main` (veya `master`) dalını ve `/ (root)` klasörünü seçip **Save** butonuna tıklayın.
5. 1-2 dakika içinde GitHub size canlı web bağlantınızı (`https://...`) verecektir!
