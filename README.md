## 🛠️ GitHub Pages Kurulumu (Nasıl Yayına Alınır?)

1. GitHub hesabınızda oturum açın ve **New repository** (Yeni repo) oluşturun (Örn: `cv` veya `<kullanici-adiniz>.github.io`).
2. Bu klasördeki dosyaları repoya yükleyin (Git komutları ile veya GitHub web arayüzünden sürükleyip bırakarak).
3. GitHub reponuzda **Settings (Ayarlar) > Pages** sekmesine gidin.
4. **Branch** kısmında `main` (veya `master`) dalını ve `/ (root)` klasörünü seçip **Save** butonuna tıklayın.
5. 1-2 dakika içinde GitHub size canlı web bağlantınızı (`https://...`) verecektir!
